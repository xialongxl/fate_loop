- Boss 词缀随机分配与运行时效果接入。
- Run 状态模型：准备、战斗、奖励、商店、结束。
- 战后奖励三选一数据生成。
- 灵魂碎片商店和基础局内成长效果。
- 生命值跨 Boss 战保留，战地修复和能量核心会影响后续战斗。
- Memory 存档适配器和 IndexedDB 存档适配器。
- Run 流程控制器和战斗结果回传契约。
- 主菜单、战前准备、战后奖励、商店和 Run 结束界面。
- 战前准备界面接入技能序列编辑器。
- Meta 永久成长：记忆碎片、初始生命、初始能量升级。
- Meta 独立存档和主菜单/Run结束成长入口。
- 战前 Boss 遭遇队列预览，显示当前、已清除和未解锁遭遇。
- Boss 遭遇队列地图化节点展示。
- Run 结束后结算记忆碎片并清理 active-run 存档。
- 奖励和商店卡片动画、屏幕切换动画和可关闭音频反馈。
- IndexedDB 真实适配器回归测试。

## 当前流程

```text
主菜单
  -> 战前准备
  -> Boss 战
  -> 奖励选择
  -> 灵魂碎片商店
  -> 下一场战前准备
  -> Run 结束
```
